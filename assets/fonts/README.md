# Preview fonts

These fonts are used only by the gallery previews (`src/gallery.py`). They make the "sample Arabic text"
view show the templates' default font stack, `"Noto Naskh Arabic", "Amiri", serif`. The templates
themselves name the fonts and do not include them.

| Family | Files | Author | Licence |
|---|---|---|---|
| Noto Naskh Arabic | `NotoNaskhArabic-*.ttf` | Google / Noto project | SIL Open Font License 1.1 |
| Amiri | `Amiri-*.ttf` | Khaled Hosny | SIL Open Font License 1.1 |

Copied from OCRSmith's bundled fonts (`D:\code\OCR\ocrsmith\assets\fonts`). The OFL allows using and
redistributing the fonts, including bundled with other software, as long as they are not sold on their own.
